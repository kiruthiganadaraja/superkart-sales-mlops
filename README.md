# superkart-sales-mlops
End-to-end ML solution that forecasts product-level store sales for SuperKart, deployed as a Flask REST API backend and Streamlit UI on Hugging Face Spaces to support inventory, pricing, and merchandising decisions.

SuperKart — Sales Prediction & End-to-End ML Deployment

SuperKart operates a retail chain of supermarkets and food marts across Tier 1, Tier 2, and Tier 3 cities. Accurate sales forecasting is critical for optimizing inventory, planning regional strategies, supporting the supply chain, and reducing forecast risk. SuperKart partnered with a data science firm to not only build a predictive model from historical sales data, but to deploy a production-ready forecasting solution that integrates directly into their decision-making workflows across stores.

This project delivers a complete machine learning pipeline — from EDA and model building through hyperparameter tuning, serialization, and full-stack deployment — that predicts the total revenue generated by each product in each store.

Key objectives

Build an accurate regression model for product-store sales forecasting
Identify the key product and store attributes driving sales
Deploy the model as a REST API for programmatic access
Provide an interactive UI for business users to generate predictions on demand
Translate model insights into actionable merchandising and inventory recommendations
Dataset

8,763 records across 12 features
Product attributes: Product_Id, Product_Weight, Product_Sugar_Content, Product_Allocated_Area, Product_Type, Product_MRP
Store attributes: Store_Id, Store_Establishment_Year, Store_Size, Store_Location_City_Type, Store_Type
Target: Product_Store_Sales_Total
Approach

EDA — univariate analysis (distributions, boxplots, frequency tables), bivariate analysis (correlation heatmap, scatter plots, mean-by-category bar plots), and multivariate pair-plots
Data validation — numeric range checks (no negatives, zeros, or out-of-range values) and categorical anomaly detection (e.g., "reg" standardized to "Regular")
Preprocessing — dropped high-cardinality identifiers (Product_Id, Store_Id), fixed categorical inconsistencies, applied One-Hot Encoding to categorical variables via a ColumnTransformer pipeline
Modeling — built and compared Random Forest Regressor and XGBoost Regressor baselines
Hyperparameter tuning — RandomizedSearchCV with 5-fold cross-validation, optimized on negative RMSE
Model evaluation — RMSE, MAE, R², and Adjusted R² on the held-out test set
Serialization — final model saved with joblib for deployment
Backend deployment — Flask REST API (with /predict and /predict_batch endpoints) containerized with Docker and hosted on Hugging Face Spaces
Frontend deployment — Interactive Streamlit UI containerized with Docker, hosted on a separate Hugging Face Space, communicating with the backend API
Final result — Tuned XGBoost Regressor

RMSE: 287.53
MAE: 120.01
R²: 0.9275
The tuned XGBoost model explains ~93% of the variance in product-store sales and significantly outperforms the tuned Random Forest baseline (RMSE 318.22, R² 0.9113). Product_MRP, Product_Weight, and Product_Allocated_Area emerged as the strongest predictors, with Store Type, Store Size, and City Tier also contributing meaningfully.

Business recommendations

Prioritize shelf space and inventory for high-MRP, high-velocity SKUs
Launch premium SKUs first in Tier 1 and Tier 2 stores
Reposition or reduce No Sugar variants in low-performing locations
Implement tier-based pricing strategies aligned with city type
Modernize older stores and integrate model predictions into weekly replenishment planning
Deliverables: Cleaned dataset, EDA notebook, trained and tuned regression models, serialized production model (best_xgb_model.pkl), Dockerized Flask backend, Dockerized Streamlit frontend, deployed Hugging Face Spaces, and a strategic recommendations report for SuperKart's merchandising and operations teams.
